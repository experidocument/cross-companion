Sync your journal to a Google Doc

About two minutes, once. The script runs in your own Google account, so your words only ever go to your Doc.

  1. On a computer, create a new Google Doc (try docs.new) and name it something like Crossword Journal.
  2. In the Doc, open Extensions → Apps Script.
  3. Delete the sample code, paste the script below and click Save.
  4. Click Deploy → New deployment. Choose the gear icon, then Web app.
  5. Set Execute as to Me and Who has access to Anyone. Click Deploy.
  6. Google asks you to authorize the script. Review it, then allow it to edit your documents.
  7. Copy the Web app URL (it starts with https://script.google.com/macros/s/).
  8. In Cross Companion, open the lightbulb → Journal → the gear icon, paste the URL and tap Save.
Keep the URL private: anyone with it can add text to that Doc. If it leaks, create a new deployment and archive the old one.
Each entry lands as a bullet under its category header (like 🎬 Film & TV). Sync all only sends entries marked New, so nothing is duplicated.
Set this up with an earlier version of the app? Paste the new script below, then use Deploy → Manage deployments → Edit → New version. Changed the script later? Use Deploy → Manage deployments → Edit → New version so the URL stays the same.
